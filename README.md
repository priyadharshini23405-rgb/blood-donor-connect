# 🩸 Blood Donor Connect

**Blood Donor Connect** is a UI/UX prototype designed to help users find blood donors, request blood, register as donors, and locate nearby hospitals.

## 🎯 Project Objective

The main objective of this project is to create a simple and user-friendly blood donation platform that connects blood donors with people who need blood.

## ✨ Features

* 🩸 Blood donor registration
* 🔎 Search for blood donors
* 🏥 Find nearby hospitals
* 🚨 Emergency blood request
* 📋 Blood request form
* 👥 View nearby blood donors
* 📞 Contact donors/hospitals
* 🔐 Login and registration screens
* 📱 Simple and easy-to-use interface

## 📱 Screens Included

1. Splash Screen
2. Home Screen
3. Login Screen
4. Donor Registration Screen
5. Search Donor Screen
6. Blood Request Screen
7. Nearby Blood Donors Screen
8. Nearby Hospitals Screen

## 🎨 Design

The design uses a clean interface with red as the primary color to represent blood donation and emergency actions. The prototype includes interactive navigation between the major screens.
